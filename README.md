# Java Day 22 - Sum of Even Numbers

This program calculates the sum of even numbers from 2 to 20 using a `while` loop.

## Output

```text
Sum of even numbers = 110
```

## Concepts Used

* `while` loop
* Variables
* Addition
* Increment by 2
* `System.out.println()`

## How It Works

The program starts with `number = 2` and `sum = 0`. The `while` loop adds each even number to `sum` until the number becomes greater than 20. The number increases by 2 in each iteration.

## What I Learned

I learned how to calculate the sum of even numbers using a `while` loop in Java.
